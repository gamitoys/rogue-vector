GitHub Pages (gamitoys.github.io) はリポジトリ設定で有効になるまで 404 です。 今すぐ遊ぶ / ホーム画面に追加するには、下の jsDelivr を Safari で開いてください。

このページ（HTTPS）

  1. 上のリンクを Safari で開く
  2. 共有 → ホーム画面に追加
  3. 追加したアイコンから起動

Pages を有効にする手順（1回だけ）:

  1. GitHub で rogue-vector を開く
  2. Settings → Pages
  3. Build and deployment → Source を Deploy from a branch
  4. Branch: main / folder: / (root) → Save

有効後の本番URL: https://gamitoys.github.io/rogue-vector/
